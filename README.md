# ElectroCore Analyzer — data and analysis scripts (MethodsX)

This repository contains every measured data set used in the MethodsX method article

> A. Zarkasi, D.R. Santoso, A. Naba, Masruroh, *ElectroCore Analyzer: an integrated workflow for
> electrochemical impedance acquisition, validation and identifiability-aware equivalent-circuit
> fitting*, MethodsX (2026, submitted).

together with scripts that recompute every data-derived number of the article and regenerate its
data figures (Figs. 6–8). The ElectroCore Analyzer software and firmware themselves are **not**
included; they are available from the corresponding author (dieks@ub.ac.id) on reasonable request.

## Contents

```
data/
  raw/                         original ElectroCore Analyzer v2.1 exports (unchanged)
    dataset_A/                 passive Rs-(R1||C1) network  (article: dataset A, worked example)
    dataset_B/                 passive Rs-(R1||C1)-(R2||C2) network (article: dataset B)
    ferri_ferrocyanide/        10, 15 and 20 mM equimolar K3/K4[Fe(CN)6] spectra (article: Fig. 8)
  processed/                   the same data as plain CSV (generated by scripts/export_csv.py)
results/
  reproduced_numbers.csv       every data-derived number of the article, recomputed, with PASS/FAIL
  sensitivity_analysis.csv     selected model under varied rule settings (Method validation, Sec. 5)
  correlation_M13_datasetB.csv correlation matrix of the selected M13, dataset B (Fig. 7b)
  correlation_M14_datasetB.csv correlation matrix of M14, dataset B (Fig. 7c)
scripts/
  ecore_io.py                  readers for the exports
  ecore_kk.py                  independent linear Voigt Kramers-Kronig test, Eqs. (1)-(3)
  export_csv.py                raw exports -> data/processed/*.csv
  reproduce_numbers.py         recomputes the numbers of the article -> results/reproduced_numbers.csv
  fig6_passive_networks.py     Fig. 6
  fig7_identifiability.py      Fig. 7
  fig8_ferri_ferrocyanide.py   Fig. 8
  reproduce_all.py             runs all of the above
  software_rerun/              scripts that re-execute the ElectroCore routines headless
                               (need the software; used for sensitivity_analysis.csv and the correlation matrices)
figures/                       output of the figure scripts
```

## Quick start

```bash
pip install -r requirements.txt
python scripts/reproduce_all.py
```

`reproduce_numbers.py` prints one line per quantity (48 in total) and writes
`results/reproduced_numbers.csv`; all of them reproduce the values printed in the article.

## Data description

**Sign convention.** Z = Z′ + jZ″, so a capacitive point has Z″ < 0. In the fitted-session exports
(`Hasil_Fitting_*.xlsx`, sheet `Fitted_Data`) the column `Z_Imag` is Z″ (negative). In the measurement
exports (`PLN_*_mM.xlsx`, sheet `EIS_Data`) the column `Z_Imag` is −Z″ (positive). The CSV files in
`data/processed/` all use Z″.

| Article | Raw file | Content |
|---|---|---|
| Dataset A (Sec. 10; Tables 7–8; Fig. 6a–c) | `dataset_A/Hasil_Fitting_1_Puncak.xlsx` | fitted session: spectrum and fit, parameters, metrics, residual statistics, automatic ranking |
| | `dataset_A/model_comparison_1_puncak.xlsx` | model-comparison export of the same search |
| Dataset B (MV Secs. 1–4; Tables 9–10; Figs. 6d–f, 7) | `dataset_B/Hasil_Fitting_2_Puncak.xlsx`, `model_comparison_2_puncak.xlsx` | as above |
| Ferri/ferrocyanide (MV Sec. 6; Fig. 8) | `ferri_ferrocyanide/PLN_{10,15,20}_mM.xlsx` | raw spectra and measurement settings |

**Dataset A** — discrete-component network Rs–(R1 ∥ C1), nominal Rs = R1 = 1 kΩ (colour code; the
capacitor value was not recorded), 10 Hz – 100 kHz. Three contiguous points between 47.1 and 68.7 kHz
were masked at inspection; the export contains the 47 retained points.

**Dataset B** — Rs–(R1 ∥ C1)–(R2 ∥ C2), nominal Rs = R1 = R2 = 1 kΩ, C1 = 470 nF, C2 = 33 nF,
50 points, 10 Hz – 100 kHz. In the export the 470 nF arc is named `Rct`/`Cdl` and the 33 nF arc
`R2`/`C2` (capacitances in pF); the article calls them R1/C1 and R2/C2.

**Ferri/ferrocyanide** — equimolar K3[Fe(CN)6]/K4[Fe(CN)6] at 10, 15 and 20 mM, prepared by mixing
100 mM stock solutions of K4[Fe(CN)6], K3[Fe(CN)6] and KCl (supporting electrolyte), measured at a
circular planar three-electrode sensor: 10 Hz – 100 kHz, 50 points, 10 mV, 0 mV bias, R_TIA = 1 kΩ,
PGA 1.5 (`data/processed/ferri_ferrocyanide_measurement_settings.csv`).

Common acquisition settings: AD5941-based ElectroCore analyzer, modulus weighting with IRLS for all fits,
Python 3.9.13 host software (ElectroCore Analyzer v2.1).

## What is recomputed and what is taken from the software

* **Recomputed independently** (`reproduce_numbers.py`): all Kramers–Kronig statistics, including the
  M dependence, the windowed and |Z|⁻¹-weighted checks and the sign-free L case; AIC, AICc, BIC,
  ΔAIC, ΔBIC, the t- and F-tests; the Brug capacitance; the parameter deviations from nominal values;
  the Durbin–Watson, kurtosis, Shapiro–Wilk and Q–Q statistics. `ecore_kk.py` reproduces the software's
  exported χ²_KK of dataset B (7.29 × 10⁻⁵) to three digits.
* **Taken from the software**: the automatic rankings and identifiability penalties (read from the
  exports), and the sensitivity analysis and correlation matrices in `results/`, which were obtained by
  re-executing the software's own fitting, identifiability and ranking routines without the interface
  (`scripts/software_rerun/`; these scripts need the ElectroCore source).
